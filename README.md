# Бюджет

PWA для быстрого учёта семейных трат в Google-таблицу: сумма → категория → «Записать».

- Остаток на сегодня и лимит на день — считаются формулами в самой таблице (лист «Свод»)
- Ожидаемые платежи на 14 дней, последние операции с изменением и удалением
- Расходы и доходы, факт и план
- Работает оффлайн: записи копятся в очереди и уходят, когда появится сеть
- Тёмная тема по настройке телефона

## Как устроено

| Слой | Где |
|---|---|
| Данные и все расчёты | Google-таблица (листы «Транзакции», «Справочники», «Свод», «Календарь») |
| API | Google Apps Script — [gas/](gas/) |
| Приложение | Статика на GitHub Pages: `index.html`, `app.js`, `styles.css`, `sw.js` |

Адрес API в код не зашит: он вводится при первом запуске и хранится только на телефоне.

## Обновление приложения

После правок файлов оболочки поднять `VERSION` в [sw.js](sw.js) — иначе телефоны останутся на старой версии из кеша.
